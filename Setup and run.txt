## Step 1: Domain Kharido (One-time + Yearly Renewal)

Domain ek baar ka paisa nahi hai — yearly renewal hota hai. Lekin bahut sasta hai.

| Provider | Price (approx) | Recommendation |
|---|---|---|
| [Cloudflare Registrar](https://dash.cloudflare.com) | ₹700-800/year | ✅ Sabse sasta, no markup |
| [Namecheap](https://namecheap.com) | ₹600-900/year | Good for beginners |
| [GoDaddy](https://godaddy.com) | ₹99 first year, then ₹999+ | Pehle sasta, baad mein mehenga |

Tip: .com domain lo — sabse trusted hai. Jaise quicktoolkit.com, toolboxfree.com

### Domain kaise kharide (Namecheap example):
1. [namecheap.com](https://namecheap.com) jao
2. Search bar mein apna naam type karo (e.g. quicktoolkit)
3. Available hai toh "Add to Cart" → Checkout
4. Account banao → Payment karo (Credit/Debit card, UPI, PayPal)
5. Done! Domain tumhara hai 1 saal ke liye

## Step 2: Free Hosting Setup (Cloudflare Pages)

Yeh 100% free hai — koi paisa nahi lagta. Unlimited bandwidth.

### A. Pehle GitHub pe code upload karo:

1. [github.com](https://github.com) pe free account banao
2. "New Repository" click karo → naam do toolbox → Create
3. Apne computer pe terminal kholo:

bash
cd ~/toolbox
git init
git add .
git commit -m "first commit"
git remote add origin https://github.com/TUMHARA_USERNAME/toolbox.git
git branch -M main
git push -u origin main

(GitHub username/password ya token mangega — enter karo)

### B. Ab Cloudflare Pages se connect karo:

1. [dash.cloudflare.com](https://dash.cloudflare.com) pe free account banao
2. Left menu → Workers & Pages → Create → Pages tab
3. Connect to Git → GitHub authorize karo
4. Apna toolbox repo select karo
5. Settings:
   - Build command: (khali chhodo)
   - Build output directory: /
6. Save and Deploy click karo
7. 1-2 minute mein live ho jayega: toolbox-xyz.pages.dev

### C. Custom domain connect karo:

1. Cloudflare Pages dashboard → apni site → Custom domains
2. Apna domain add karo: quicktoolkit.com
3. Agar domain Cloudflare pe kharida hai → automatic connect
4. Agar Namecheap/GoDaddy pe hai → Cloudflare ke nameservers set karo:
   - Namecheap dashboard → Domain → Nameservers → Custom DNS
   - Cloudflare ke 2 nameservers paste karo (Cloudflare dashboard mein dikhega)
   - 5-30 minutes mein connect ho jayega
5. SSL/HTTPS automatic free mil jayega ✅

## Step 3: Google Search Console (Free — Google pe aao)

1. [search.google.com/search-console](https://search.google.com/search-console) jao
2. "Add Property" → apna domain dalo: quicktoolkit.com
3. Verify karo (Cloudflare DNS method sabse easy)
4. Left menu → Sitemaps → URL dalo: https://quicktoolkit.com/sitemap.xml → Submit
5. Google ab tumhari site crawl karega — 3-7 din mein pages dikhne lagenge

## Step 4: Google Analytics (Free — Traffic track karo)

1. [analytics.google.com](https://analytics.google.com) jao
2. Account banao → Property banao → Web select karo
3. Tumhara domain dalo
4. Ek tracking code milega, kuch aisa:
html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXX');
</script>

5. Yeh code apni har HTML file ke <head> mein paste karo
6. Ab tumhe real-time dikhega kitne log site pe hain

## Step 5: Google AdSense Apply (Earning shuru)

Important: AdSense apply karne se pehle 2-3 weeks wait karo — kuch traffic aane do.

1. [adsense.google.com](https://adsense.google.com) jao
2. Sign up → apna domain dalo
3. Ek code milega → index.html ke <head> mein paste karo
4. Apply karo → Google review karega (1-14 din lagta hai)
5. Approve hone pe ad slots mein AdSense code dalo

### AdSense approval ke liye zaroori:
- ✅ Privacy Policy page (already hai)
- ✅ About page (already hai)
- ✅ Contact page (already hai)
- ✅ Original useful content (tumhare tools)
- ✅ Minimum 15-20 pages (tumhare paas 17 hain)
- ✅ Domain at least 2-3 weeks purana ho
