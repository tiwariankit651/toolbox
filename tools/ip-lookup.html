About This Tool

This IP & Network Toolkit is built around honesty about what a static web page can and cannot do. A page running only in your browser cannot look up the geolocation of an arbitrary IP address on its own — that requires a database held by an external service. So this tool separates the features clearly: the parts that work purely in your browser (connection info, WebRTC local-IP detection, and a full offline IP/subnet toolkit) run with no network requests at all, while public-IP geolocation is an optional, clearly-disclosed feature that sends a request to the third-party service ipapi.co only when you press a button.

The My Connection tab reflects only information your browser genuinely exposes to any web page: user agent, parsed browser/OS/device, screen and viewport size, colour depth, device pixel ratio, CPU core count, device memory (where exposed), language list, timezone, cookie and do-not-track settings, online status, Network Information API estimates, battery status (where available), and touch support. The IP Toolkit validates IPv4 and IPv6 addresses, converts IPv4 to and from its 32-bit integer form, runs a full CIDR/subnet calculator, splits subnets, checks CIDR membership, and identifies private, loopback, link-local, multicast and reserved ranges.

Frequently Asked Questions

Is this tool really free?

Yes, completely free with no hidden charges, no signup required, and no usage limits. Use it as many times as you want.

Does the public IP lookup send my data anywhere?

Yes — and only when you press the lookup button. The public IP lookup sends a request from your browser directly to ipapi.co, a third-party geolocation service, which processes the request under its own privacy policy. All other tabs (connection info, WebRTC, and the IP toolkit) run entirely in your browser and make no requests.

Why does WebRTC show a .local hostname instead of an IP?

Modern browsers deliberately mask your real local IP address behind an mDNS hostname (ending in .local) to protect your privacy. Seeing this instead of a real address means your browser's privacy protection is working.

Does the IP toolkit need an internet connection?

No. Validation, subnet calculation, CIDR checks, and IPv4/integer conversion all run offline in your browser using JavaScript.

How accurate is IP geolocation?

IP geolocation from any service (including ipapi.co) is typically accurate only to the city or region level, and VPNs, proxies, and mobile carriers can show a very different location. Treat it as approximate.

Can I look up private IPs like 192.168.x.x?

Private, loopback, and link-local addresses are not routable on the public internet and cannot be geolocated. The offline toolkit will still validate and classify them for you.
