📋 Syllabus Progress Tracker

Select an exam or create custom syllabus. Check off completed topics. Auto-saves to browser.

About This Tool

Track your exam syllabus completion with visual progress. Pre-built checklists for UPSC Prelims (25 topics), SSC CGL (19 topics), and Banking IBPS PO (20 topics). Create custom syllabi for any exam. Check off topics as you complete them — see progress bar fill up with percentage. Export your progress as JSON backup (survives browser cache clear). Import progress from backup. Print your tracker for wall display. All data saves automatically in your browser. Essential for organized exam preparation.
