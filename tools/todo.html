A focused, list-based task manager with projects, priorities, due dates, subtasks, recurring tasks, smart views and stats. Auto-saves to your browser.

    ⌨️ Keyboard Shortcuts

    • Enter in the add box — add the task
    • ↑ / ↓ — move focus between tasks
    • Space or Enter on a focused task — toggle complete
    • E on a focused task — edit it
    • Delete on a focused task — delete it

    How to Use This Tool

    Tasks ka list banana hai? Priority set karo, due date lagao. Kaam hone pe "Done" mein move karo. Simple Kanban board — Trello jaisa but free aur instant.

    1. Task likho aur priority choose karo — High, Medium, ya Low
    2. Due date lagao agar deadline hai — overdue hone pe red dikhega
    3. Task shuru karo toh "Doing" mein move karo — progress track hoga
    4. Complete hone pe "Done" mein bhejo — satisfaction milega ✅
    5. "Clear Done" se purane tasks hatao — board clean rakho

    About This Tool

    A Kanban-style task board with three columns: To Do, Doing, and Done. Add tasks with priority levels (High/Normal/Low) and optional due dates. Move tasks between columns as you work on them. Color-coded priority indicators and due date display. Clear completed tasks with one button. All data saves automatically in your browser. Perfect for managing study plans, project tasks, daily activities, assignment tracking, and any workflow that benefits from visual task organization.
