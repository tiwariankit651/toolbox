SQL Pattern Reference

Joins Explained

  • INNER JOIN — only rows matching in both tables. SELECT * FROM a INNER JOIN b ON a.id = b.a_id
  • LEFT JOIN — all rows from the left table, matched rows from the right (NULLs where none match).
  • RIGHT JOIN — all rows from the right table, matched from the left.
  • FULL OUTER JOIN — all rows from both sides, matched where possible.
  • CROSS JOIN — every combination (Cartesian product). Use with care.

Aggregate Functions

  • COUNT(*), SUM(col), AVG(col), MIN(col), MAX(col) — usually paired with GROUP BY.
  • Filter groups with HAVING: SELECT dept, COUNT(*) FROM emp GROUP BY dept HAVING COUNT(*) > 5

Window Function Syntax

  • ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC)
  • RANK(), DENSE_RANK(), LAG(col), LEAD(col), SUM(col) OVER (...) for running totals.
