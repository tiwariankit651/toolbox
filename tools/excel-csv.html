How to Use This Tool

  1. Excel → CSV: Drop your workbook in. If it has several sheets, pick the one you need from the dropdown — each sheet becomes its own CSV.
  2. Choose the separator: Comma is standard, but if your Excel uses Indian or European regional settings, semicolon is often what it expects back.
  3. Keep the BOM on if you plan to reopen the CSV in Excel. Without it, Excel can mangle Hindi text, names with accents and the ₹ symbol — Excel to CSV Kaise Kare — Aur Jo Problems Aati Hain Unka Asli Fix.
  4. CSV → Excel: Drop a CSV or paste rows, then download a real .xlsx that opens cleanly in Excel, Google Sheets or LibreOffice.
  5. Check the preview before downloading — if the columns look wrong, the separator is usually the reason.

About This Tool

Convert between Excel and CSV without installing anything or signing up. The file is parsed by your own browser using the SheetJS library, so a salary sheet, student list or sales register never leaves your device — there is no server to upload it to. Supports .xlsx, .xlsm and older .xls workbooks, picks up every sheet in the file, and writes CSV with an optional UTF-8 byte order mark so Excel reopens Hindi, Marathi, Tamil and ₹ amounts correctly instead of turning them into question marks. Going the other way, it writes a genuine .xlsx with a bold header row and column widths fitted to your content, not a CSV renamed with a different extension.

Frequently Asked Questions

Is my spreadsheet uploaded to a server?

No. The file is read and converted by your browser. There is no upload step, which is why it also works offline.

Why does Excel show my Hindi text as question marks?

Excel assumes a plain CSV is in your system's regional encoding, not UTF-8. Keep the "Excel-friendly (UTF-8 BOM)" option ticked and it will read the file as UTF-8, so Devanagari and ₹ stay intact.

My columns all landed in one column. What went wrong?

The separator does not match. Indian and European Excel installs often use semicolon rather than comma. Switch the separator and check the preview again.

Does it keep formulas and formatting?

CSV is a plain-text format, so it stores the calculated values rather than the formulas, and no colours or fonts. That is a limitation of CSV itself, not of this tool.

What is the largest file it can handle?

It is limited by your device's memory rather than a fixed cap. Workbooks up to a few tens of thousands of rows are comfortable on a typical phone; very large files are better split first.

Does it work on mobile?

Yes. The preview table scrolls sideways and the buttons are sized for touch.
