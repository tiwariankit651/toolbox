Frequently Asked Questions

Can I start numbering at a page other than 1, or from a different number?

Yes, both. The "Start number" box sets what the first numbered page is labelled — set it to 5 and the sequence runs 5, 6, 7… The "Pages to number" box controls which pages actually get a stamp: type all, a range like 3-10, or a list like 1,4,6. There is also a "Skip first page (cover)" checkbox that leaves page 1 blank while still numbering the rest, which is the usual choice for a document with a title page.

What number formats are available?

Five: a plain number (1), "Page 1", "1 of N", "Page 1 of N", and "- 1 -". The "of N" formats use the total count of pages that are actually being numbered and the start number, so if you number pages 3-10 starting at 1 the last page shows "8 of 8". You also choose the position (bottom or top, left/center/right), the font size in points, the margin from the edge, and the colour.

Will the number land correctly on a page that is rotated or a different size?

Yes. Each page is measured on its own, so a file that mixes A4, Letter and landscape pages gets its number placed against the correct edge of every page. Pages that carry a /Rotate value are handled in their visual orientation — the tool works out where the bottom-right (or whichever corner you picked) is after rotation and draws the number there, upright, rather than in the unrotated corner.

How do I check the placement before downloading?

A live preview rendered with pdf.js shows page 1 and, if it differs, the first page that will actually be numbered, with the number drawn on top exactly where it will appear. As you change position, format, size, margin or colour the preview updates, so you can confirm the look before clicking Add Page Numbers & Download. The output is saved with the standard Helvetica font via pdf-lib and downloads as your-file-numbered.pdf; nothing is uploaded.

Getting page numbers exactly where you want them

Adding page numbers sounds trivial until the first page is a cover, the document continues from an earlier file, or half the pages were scanned sideways. This tool is built around those awkward cases: you choose the corner, the wording, where the count starts and which pages get touched, and a live preview confirms the result before you commit. Everything happens in your browser through pdf-lib, so the PDF is never uploaded.

Start number versus the range of pages to number

Two settings are easy to confuse, so it helps to treat them separately. The "Pages to number" box decides which pages receive a stamp — all, a range such as 3-10, or a comma list like 1,4,6. The "Start number" decides what the first stamped page is labelled. If a report begins with two unnumbered front pages, set the range to 3-10 and the start to 1, and page three reads "1". For a volume that continues from another document, leave the range on all and set the start to, say, 24. The "Skip first page (cover)" checkbox is a shortcut that drops page one from the numbered set regardless of the range, which is the common title-page case.

Choosing a format that counts correctly

Five formats are offered: a plain 1, Page 1, 1 of N, Page 1 of N, and - 1 -. The two "of N" variants are worth understanding, because N is the number of pages actually being numbered, not the raw page count of the file. Number pages 3 to 10 and the last one shows "8 of 8", because eight pages were stamped. This keeps the totals honest when you deliberately leave some pages unnumbered. Position, font size in points, margin from the edge, and colour are all independent, so a discreet grey "1" in the bottom-right and a bold "Page 1 of 20" centred at the top are both a few clicks away.

Why rotated and mixed-size pages still work

A PDF can mix A4, Letter and landscape pages in one file, and individual pages can carry a /Rotate flag that turns them when displayed. The tool measures every page on its own and, for a rotated page, computes where your chosen corner sits in the visual orientation the reader sees, then maps that point back into the page's real coordinate space and pre-rotates the text so it reads upright. In practice that means a page stored portrait but rotated 90° for viewing still gets its number in the visual bottom-right, the right way up — not stranded in the unrotated corner.
