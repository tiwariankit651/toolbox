Frequently Asked Questions

What gradient types are supported?

Linear (directional), Radial (circular/elliptical from a point), Conic (angular sweep), and Repeating-linear (pattern). All use standard CSS syntax.

Can I add more than 3 colors?

Yes! Click "Add Color Stop" to add unlimited colors. Each stop has its own color picker and position slider.

How do I use the generated CSS?

Copy the CSS code and paste it as the background property of any HTML element in your stylesheet.

Can I download the gradient as an image?

Yes! Click "Download PNG" to save the gradient as a 1920x1080 PNG image for use in presentations, social media, or design projects.
