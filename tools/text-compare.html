Which Metric Should I Use?

  • Levenshtein — best for spotting small typos and character-level edits
  • Jaro-Winkler — best for names and short strings where the start matters
  • Jaccard / Dice — best when word overlap matters more than order
  • Cosine — best when texts differ in length but share vocabulary
  • LCS substring — finds the longest identical passage (useful for plagiarism)

About This Tool

This is a text similarity analyzer. It computes multiple industry-standard similarity metrics — Levenshtein edit distance, Jaro-Winkler, Jaccard word-set overlap, cosine similarity on term-frequency vectors, the Dice coefficient, and the longest common substring — then blends them into an overall verdict with a visual meter. It highlights the passages the two texts share, breaks words down into "only in A", "only in B" and "common", and shows a side-by-side statistics table (characters, words, sentences, paragraphs, unique words, average word length, and a Flesch readability score). A fuzzy-match mode gives a clear match / no-match answer for short strings like names and addresses, and a batch mode compares whole lists of string pairs and exports the results as CSV. If instead you want to see exactly which lines changed, use the Diff Checker. Everything runs in your browser — your text is never uploaded.
