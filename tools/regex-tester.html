🔍 Regex Tester

Test regular expressions with real-time matching and highlights.

📖 Regex Cheat Sheet
.Any character except newline
*0 or more (e.g. a*)
+1 or more (e.g. \d+)
?0 or 1 (optional) (e.g. colou?r)
\dDigit [0-9]
\wWord char [a-zA-Z0-9_]
\sWhitespace (space, tab, newline)
^Start of string/line
$End of string/line
[abc]Character class — matches a, b, or c
(abc)Capturing group
a|bAlternation — a or b
{n,m}Between n and m repetitions
(?=...)Lookahead — matches if followed by ...
(?<=...)Lookbehind — matches if preceded by ...
gGlobal — find all matches, not just the first iCase-insensitive — ignore upper/lower case mMultiline — ^ and $ match line starts/ends sDotall — dot (.) also matches newline characters uUnicode — treat pattern as Unicode code points

About This Tool

Test and debug JavaScript regular expressions in real-time. Enter a pattern and test string — matches are highlighted instantly with match count. Supports all JavaScript regex flags (g, i, m, s, u). Includes Replace mode — enter a replacement string and see the result live. Common pattern presets: email, phone (10 digit), URL, IP address, date (YYYY-MM-DD), and HEX color. Essential for developers working with text parsing, form validation, data extraction, and string manipulation.
