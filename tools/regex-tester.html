About This Tool

Test and debug JavaScript regular expressions in real-time. Enter a pattern and test string — matches are highlighted instantly with match count. Supports all JavaScript regex flags (g, i, m, s, u). Includes Replace mode — enter a replacement string and see the result live. Common pattern presets: email, phone (10 digit), URL, IP address, date (YYYY-MM-DD), and HEX color. Essential for developers working with text parsing, form validation, data extraction, and string manipulation.

Frequently Asked Questions

Which regex flags and features does it support?

All six JavaScript flags via checkboxes: g (global), i (case-insensitive), m (multiline), s (dotall), u (unicode) and y (sticky). It shows live highlighting of matches, a match count, and per-match details including every capturing group by number and named groups like (?<name>). A Replace tab supports $1, $2 and $<name> references with live preview.

Are there ready-made patterns?

Yes, 17 presets, each with a sample test string: email, Indian mobile, Indian PIN code, PAN card, Aadhaar, GSTIN, IFSC code, URL, IPv4, date dd/mm/yyyy, time, hex colour, username, strong password, HTML tag, whitespace and duplicate words. A collapsible cheatsheet covers character classes, quantifiers, anchors, groups, lookarounds and escapes.

Does it warn about common regex mistakes?

Yes — a feature most testers lack. Beyond reporting syntax errors, it flags patterns that are valid but likely to surprise you: a dot not crossing newlines without the s flag, ^/$ anchoring to the whole string without m, only the first match without g, nested quantifiers that risk catastrophic backtracking, a literal dot inside a character class, and \d/\w matching ASCII only under the u flag.

Does it remember my work?

Yes. Your pattern, test string, replacement and flags are saved locally so they survive a reload. Patterns that actually matched something are kept in a history list (up to 10) you can reload with one click. Press Ctrl/Cmd+Enter or R to re-run. Everything runs in your browser with no server component.
