Character Classes
.Any character except newline
\dDigit [0-9] — e.g. \d+ matches "123"
\DNon-digit [^0-9]
\wWord char [a-zA-Z0-9_] — e.g. \w+ matches "hello_1"
\WNon-word character
\sWhitespace (space, tab, newline)
\SNon-whitespace
[abc]Any of a, b, or c
[^abc]Not a, b, or c
[a-z]Range: a to z
Quantifiers
*0 or more — a* matches "", "a", "aaa"
+1 or more — a+ matches "a", "aaa"
?0 or 1 (optional) — colou?r
{n}Exactly n — \d{4} matches "2024"
{n,}n or more
{n,m}Between n and m
*?Lazy * (as few as possible)
+?Lazy +
Anchors
^Start of string (or line with m flag)
$End of string (or line with m flag)
\bWord boundary — \bcat\b matches "cat" not "catch"
\BNon-word boundary
Groups & References
(abc)Capturing group — access with $1
(?:abc)Non-capturing group
(?<name>)Named group — access with $<name>
\1Back-reference to group 1
a|bAlternation — a or b
Lookarounds
(?=...)Positive lookahead — matches if followed by ...
(?!...)Negative lookahead — matches if NOT followed by ...
(?<=...)Positive lookbehind — matches if preceded by ...
(?<!...)Negative lookbehind — matches if NOT preceded by ...
Escapes
\.Literal dot
\\Literal backslash
\nNewline
\tTab
\uFFFFUnicode character
SpecialEscape these: . * + ? ^ $ { } ( ) | [ ] \

About This Tool

Test and debug JavaScript regular expressions in real-time. Enter a pattern and test string — matches are highlighted instantly with match count. Supports all JavaScript regex flags (g, i, m, s, u). Includes Replace mode — enter a replacement string and see the result live. Common pattern presets: email, phone (10 digit), URL, IP address, date (YYYY-MM-DD), and HEX color. Essential for developers working with text parsing, form validation, data extraction, and string manipulation.
