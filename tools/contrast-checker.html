WCAG Standards

AA Normal Text: Minimum ratio 4.5:1

AA Large Text (18px+ bold or 24px+): Minimum ratio 3:1

AAA Normal Text: Minimum ratio 7:1

AAA Large Text: Minimum ratio 4.5:1

How to Use This Tool

  1. Set text color: Text readable hai ya nahi? Pehle apna foreground (text) color enter karo
  2. Set background: Background color pick karo ya hex code type karo
  3. Check the ratio: Contrast ratio automatically calculate hoga — higher is better
  4. See WCAG results: AA pass hua? AAA pass hua? Green tick matlab accessible hai
  5. Adjust till it passes: Fail ho raha hai? Colors tweak karo jab tak green na ho jaye

Common Use Cases

  • Website ka text light background pe dikh nahi raha? Check contrast here
  • Client ne accessibility compliance maanga? WCAG score verify karo
  • Dark mode design kar rahe ho? Make sure text readable hai
  • Mobile app ke colors test karne hai? Small text needs higher contrast
  • Government/public website bana rahe ho? Legal requirement hai accessibility

About This Tool

Check if your text and background color combination meets WCAG accessibility standards. Enter any two colors and instantly see the contrast ratio with pass/fail results for AA and AAA levels (both normal and large text). Includes a live preview showing how your text looks on the background, color swap button, and HEX input. Essential for web designers and developers building accessible websites that everyone can read, including people with visual impairments.
