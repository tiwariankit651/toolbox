🗣️ Text to Speech

Enter text below and click Speak. Uses your browser's built-in Web Speech engine. Available voices depend on your operating system and browser.

📝 Dictation Mode (for students)

Reads each sentence twice with a pause in between, so you can write along.

📌 Pronunciation Bookmarks

🕘 Recent Texts

ℹ️ Good to know: The available voices depend entirely on your operating system and browser — you may see more or fewer voices on different devices. The Web Speech API cannot save an audio file; there is no way to download the spoken audio directly. If you need to capture the audio, use our Screen Recorder tool while this reads aloud.

How to Use This Tool

  1. Step 1: Eyes tired from reading? Paste or type the text you want to hear
  2. Step 2: Pick a voice — there are different accents and male/female options
  3. Step 3: Adjust the speed — slow it down for learning, speed it up for quick listening
  4. Step 4: Hit Play and sit back while the computer reads it to you
  5. Step 5: Use Dictation mode for study — it repeats each sentence twice so you can write along

Common Use Cases

  • Listening to articles or documents while multitasking
  • Proofreading written content by hearing it spoken aloud
  • Creating audio versions of written content for accessibility
  • Practicing pronunciation of text in different languages
  • Generating voiceovers for presentations or videos

About This Tool

Convert any text to speech using your browser's built-in speech synthesis engine. Supports multiple voices and languages (depends on your operating system). Adjust speaking speed (0.5x to 2x), pitch and volume with live preview. Features play, pause, resume, and stop controls with a progress bar and word highlighting, long-text auto-chunking, reading presets, .txt upload, and a special Dictation mode for students. Note: the Web Speech API cannot export an audio file — to capture the audio use our Screen Recorder tool. Perfect for proofreading (hear your text read aloud to catch errors), language learning (hear correct pronunciation), accessibility (for visually impaired users), and listening to articles or study notes while doing other tasks. No external API — works offline.
