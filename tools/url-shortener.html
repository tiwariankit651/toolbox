Frequently Asked Questions

Is this tool really free?

Yes, completely free with no hidden charges, no signup required, and no usage limits.

Can a static page really create short links?

Not on its own — a real short link needs a redirect service with a backend. The Shorten tab uses the third-party is.gd API to create genuine short links, which means your long URL is sent to is.gd. All the other tools (UTM builder, parser, cleaner, encoder, QR, safety check) run entirely in your browser.

Do shortened URLs expire?

Links created via is.gd are managed by is.gd under their own terms. We do not control their lifetime.

Is my data safe?

Your saved campaigns and link history are stored only in your browser's localStorage. The offline tools never send your URLs anywhere. Only the Shorten tab sends a URL to is.gd, and only when you press the button.

Does it work on mobile?

Yes, this tool works on all devices — desktop, tablet, and mobile phone.

Can I use this for commercial purposes?

Yes, you can use the generated links for any purpose — personal, educational, or commercial.

About This Tool

The Link Toolkit is an honest set of link utilities. Because a static web page cannot host redirects on its own, real short-link creation is handled by the third-party is.gd API (clearly disclosed, and only when you press the button), while the rest of the toolkit — a UTM campaign builder with channel presets, a full URL parser and inspector, a tracking-parameter cleaner, URL component encoding and decoding, relative-to-absolute resolution, a QR code generator with PNG download, and a heuristic link-safety checklist — runs entirely in your browser. Saved campaigns and link history live only in your browser's localStorage.
