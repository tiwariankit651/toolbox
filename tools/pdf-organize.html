🗂️ Organize PDF

Reorder pages by dragging (works with touch), rotate a single page, delete pages (with undo), duplicate a page, insert a blank page, or bring in pages from a second PDF — then download. Everything runs in your browser; nothing is uploaded.

Drop a PDF here or click to browse

Frequently Asked Questions

Does dragging to reorder work on a phone?

Yes. Reordering is built on pointer events rather than the HTML5 drag-and-drop API, so the same press-and-drag gesture works with a mouse on desktop and a finger on a touch screen. A marker shows whether the page will drop before or after the card you are hovering over. Every card also has ▲ and ▼ buttons that move it one slot, which work by keyboard and are there for accessibility when dragging is not convenient.

If I delete a page by mistake, can I get it back?

Yes. Deleting one page, or several selected pages at once, stores them so an "Undo delete" button can restore them to their original positions. The button shows how many pages are waiting to be restored. Undo holds the most recent delete; once you make another delete, that becomes the undoable one. You can also select multiple pages (tap to toggle the highlight) and rotate or delete them together.

Can I combine pages from another PDF, add blanks, or duplicate a page?

Yes to all three. "Add pages from another PDF" appends every page of a second file to the grid, where you can then drag them anywhere. "Blank page at end" inserts an empty page the size of the first page in the document. The duplicate button on each card drops an identical copy right after it. Password-protected or unreadable second files are skipped with a message rather than breaking the batch.

Is the page content kept intact, and what is the saved file called?

Yes — pages are copied with pdf-lib's copyPages, which preserves the original content exactly rather than re-rendering it to an image. Any rotation you applied is added on top of the page's existing rotation, so a page already stored rotated stays correct. Blank pages are added at the chosen size. The result downloads as your-file-organized.pdf, and because everything runs in your browser the PDFs are never uploaded.

How to Use This Tool

  1. Drop your PDF — thumbnails are rendered in batches so even a long document stays responsive.
  2. Drag a page to a new position (hold and drag on touch screens), or use the ▲ ▼ arrows on each card.
  3. Rotate, delete or duplicate individual pages with the buttons on each card; deleted pages can be restored with Undo.
  4. Insert a blank page or add pages from a second PDF if you need to combine documents.
  5. Click Save Organized PDF — the new file keeps all page content and downloads as <name>-organized.pdf.

Common Use Cases

  • Fixing a scan where pages came out in the wrong order
  • Rotating sideways-scanned pages so they read upright
  • Removing blank or duplicate pages from a scanned document
  • Inserting a cover or separator page between sections
  • Pulling a few pages from one PDF into another without a full merge

About This Tool

Organize PDF lets you rearrange a document page by page without uploading anything. Thumbnails are rendered with pdf.js in small batches so large files do not freeze the tab. You can reorder pages by dragging — implemented with pointer events so it works the same with a mouse or a finger on mobile — or with the up/down arrow buttons on each card for keyboard and accessibility. Each page can be rotated 90° at a time, deleted (with an undo that restores the last removed pages), or duplicated. You can insert a blank page the size of the first page, and add pages from a second PDF that are copied in with their content intact. Whole-document actions include reverse order, sort back to the original order, select all and clear selection. When you save, pages are copied with pdf-lib's copyPages so their content is preserved exactly, any rotation you applied is added on top of the page's existing rotation, and the result downloads as your-file-organized.pdf.

Rearranging a PDF page by page without re-rendering it

Organize PDF treats a document as a tray of cards you can shuffle, turn, drop or duplicate. It is aimed at the everyday mess of scanned files: pages in the wrong order, a couple turned sideways, a stray blank in the middle, or a cover that belongs in front of everything. Because the work is done with pdf-lib and pdf.js in the browser, the file is never uploaded, and the pages that come out are the original pages — not flattened images.

Dragging that works with a mouse and a finger

Reordering uses pointer events rather than the old HTML5 drag-and-drop API. That choice matters: HTML5 dragging simply does not fire on most touch screens, so a mobile user would be stuck. Here the same press-and-move gesture drives reordering on a laptop and a phone alike, and as you move over a card a marker shows whether the dragged page will land before or after it. For keyboard users, or when precise dragging is fiddly, every card also carries ▲ and ▼ buttons that nudge it one position at a time. A small badge on each card shows its current place in the sequence so you always know what position you are editing.

Deleting safely, and acting on many pages at once

Tap a card to highlight it; tap again to clear it. With one or more pages selected you can rotate or delete them together, which is far quicker than working card by card. Deletion is reversible: the removed pages are held, and an "Undo delete" button — labelled with how many pages are waiting — puts them back in their original slots. Undo covers the most recent deletion, so delete a batch, check the result, and restore it in one click if it was wrong. Whole-document controls round this out: reverse the entire order, sort everything back to the original order, select all, or clear the selection.

Adding, duplicating and inserting pages

Three actions grow the document rather than just rearrange it. The duplicate button on a card drops an identical copy directly after it, handy for repeating a form page. "Blank page at end" inserts an empty page sized to match the first page in the grid, useful as a separator or a signature sheet. "Add pages from another PDF" appends every page of a second file, which then behave like any other card — drag them wherever they belong. A second file that is password-protected or unreadable is skipped with a message, so one bad file never derails the batch. Thumbnails for large documents are rendered in small batches so a long PDF does not freeze the tab while previews catch up.

What the saved file contains

Saving copies each page with pdf-lib's copyPages, which preserves the original content exactly. Any rotation you applied in the grid is added on top of the page's existing rotation, so a page already stored rotated ends up correct rather than double-counted. Blank pages are written at their chosen size. The output downloads as your-file-organized.pdf, and the page count shown above the grid is your quick check that the result matches what you arranged.
