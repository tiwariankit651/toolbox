How to Use This Tool

  1. Pick a type and the reminder window is set to something sensible for it — 180 days for a passport because renewal takes weeks, 15 for a PUC certificate because it is a same-day job.
  2. Add the expiry date. The list shows days remaining and colours anything inside its reminder window, so what needs attention is obvious at a glance.
  3. Export the calendar file. This is the step that matters — a list you have to remember to open is not a reminder. The .ics file adds an all-day event with an alarm to Google Calendar, Apple Calendar or Outlook.
  4. Keep a backup. The list lives in this browser only, so if you clear site data it is gone. The JSON backup restores it exactly; the CSV is for a spreadsheet.
  5. Reference numbers are optional and stay on your device. Add them if it helps you renew faster, leave them out if you would rather not store them.

Common Use Cases

  • Passport expiring within six months, which many countries refuse entry on
  • Vehicle insurance and PUC, where lapsed cover is both a fine and a real risk
  • Driving licence renewal, easy to forget until a traffic stop
  • Appliance warranty and AMC dates that are worth claiming before they lapse
  • Rent agreement renewal, which needs lead time to negotiate
  • Professional licence, certification or visa with a fixed validity
  • Fixed deposit maturity so it is not auto-renewed at a poor rate

About This Tool

Most expiry dates are missed for the same reason: they are written somewhere nobody looks until it is too late. A spreadsheet only helps if you open it, and a phone note gives no warning. This tracker does two things — it shows every document with days remaining and highlights what has entered its reminder window, and it exports a proper calendar file so the reminder arrives on your phone without you doing anything. The .ics file is a valid VCALENDAR with one VEVENT per document and a VALARM set to your chosen lead time, which is what makes Google Calendar, Apple Calendar and Outlook all notify you. Default lead times reflect how long each renewal actually takes rather than one generic number: a passport gets 180 days, vehicle insurance 30, a PUC certificate 15. Everything is stored in your browser only. There is no account, no sync and no upload, which is deliberate given that the list may hold policy and licence numbers — but it also means the backup button is not optional.

Frequently Asked Questions

Will this send me an email or an SMS?

No, and it is worth being clear about why: sending you anything would mean uploading your document list to a server. Instead it generates a calendar file, so the reminder comes from your own phone's calendar. That keeps the data with you and still gets you the alert.

Where is my list stored?

In this browser's local storage on this device. It is not synced and not uploaded. If you clear site data, use a different browser or switch devices, the list will not follow — which is what the JSON backup is for.

How do I add the .ics file to my calendar?

On a phone, open the downloaded file and your calendar app will offer to import it. On a desktop, use Import in Google Calendar settings, or open the file directly in Apple Calendar or Outlook.

Why 180 days for a passport?

Many countries require at least six months of validity remaining on arrival, so a passport can become unusable for travel well before it actually expires. Renewal also takes time. The default reflects both.

Can I track things that renew every year?

Yes. Add the next expiry date, and when you renew, update the date to the new one. The calendar export reflects whatever dates are in the list at the time you export.

Is it safe to enter policy numbers?

They stay in your browser and are never transmitted. That said, they are optional — the tracker works perfectly well with just a name and a date if you would rather not store them at all.
