How to Use This Tool

  1. Upload a photo — drag and drop or tap. iPhone HEIC files are decoded in your browser.
  2. Choose an effect — blur, pixelate, or a solid box — and a shape, rectangle or ellipse.
  3. Drag a box over each face or detail you want to hide. Add as many regions as you like; each is drawn live.
  4. Or press "Detect faces" to load the face detector and add a region over every face it finds. Always check the result — it can miss small or turned faces.
  5. Undo the last region or clear all, tune the strength, then Apply & Download. The export strips EXIF and GPS metadata.

About This Tool

Hide faces and sensitive details in a photo without any upload. Draw rectangular or elliptical regions over whatever should be concealed, then choose how to hide it: a strong Gaussian-style blur, a pixelation (mosaic) effect with an adjustable block size, or a solid colour box. The blur is deliberately destructive — the region is shrunk to a few pixels, blurred, and enlarged again, so the original detail is gone rather than merely smeared, which matters because a weak blur can sometimes be reversed or read. Optional automatic face detection uses Google's MediaPipe Tasks Vision BlazeFace short-range model, loaded only when you press the button; detected faces become ordinary editable regions you can move past or delete. The short-range model is tuned for faces within roughly two metres of the camera, so it may miss small, distant or side-on faces — always check before sharing. The canvas re-encode strips EXIF and GPS metadata from the saved file.

Frequently Asked Questions

Is the blur strong enough that it can't be undone?

The blur is deliberately destructive: the region is shrunk to a few pixels, then enlarged again with a light smoothing pass. Because the original pixels are thrown away at the downscale step, sharpening cannot bring the detail back — unlike a mild CSS-style blur that merely spreads pixels and can sometimes be reversed. That said, a light blur over small text can still occasionally be read, so for names, number plates or OTPs use a high blur strength, a large pixel block, or the solid box, which removes the content entirely.

How does the automatic face detection work, and what can it miss?

Pressing 'Detect faces' loads Google's MediaPipe Tasks Vision BlazeFace short-range model (about a few MB, Apache-2.0) only at that moment — it isn't downloaded unless you ask for it. Each detected face becomes an ordinary region you can resize, move past or delete. The short-range model is tuned for faces within roughly two metres of the camera, so it may miss small, distant or side-on faces. Always check the result before sharing. If the model fails to load, the tool says so and manual drawing keeps working.

What's the difference between blur, pixelate and solid box?

Blur softens the region into an unreadable smear (via the downscale-and-enlarge method above) and looks the most natural. Pixelate replaces it with a mosaic of large blocks whose size you set — recognisable as censoring and hard to reverse. Solid box paints a flat colour over the region, removing the content completely; it's the safest for text and IDs. Each region can also be a rectangle or an ellipse, which suits faces better.

Does saving the photo remove the location and camera data too?

Yes. The image is rebuilt on a canvas and re-encoded, which drops EXIF metadata including GPS coordinates, camera model and timestamp — so the saved file doesn't leak where or when the photo was taken. You can keep the original format or export JPG, PNG or WebP. Nothing is uploaded; the photo, the regions and the face detection all run on your device.

Hiding a detail so it stays hidden

The trap with blurring sensitive parts of a photo is that a weak blur is not the same as removing information. A gentle blur spreads each pixel into its neighbours, but the underlying values are still there in a recoverable form — researchers have repeatedly shown that lightly blurred or naively pixelated text can be reconstructed. If the thing you are hiding is a face among strangers, a soft blur is usually fine. If it is a name, an account number, a one-time code or a car number plate, "usually fine" is not good enough. This tool is built around that distinction.

How the blur is made irreversible

When you choose Blur, the selected region is not simply smeared in place. It is drawn into a tiny off-screen canvas — a few pixels across, with the exact size driven by the strength slider — and then scaled back up to fill the region, with a light smoothing pass so the edges are not blocky. Shrinking to a handful of pixels physically discards the detail; enlarging cannot invent back what was thrown away. The result looks like a smooth blur but behaves like a deletion. Turn the strength up for small or text-like content, where even a destroyed-but-large region can leave a readable silhouette.

Pixelate and solid box, and when to prefer them

Pixelate replaces the region with a mosaic whose block size you control; bigger blocks mean fewer, coarser squares and less recoverable structure. It reads clearly as "this was censored", which is sometimes exactly the signal you want. The Solid box paints a flat colour over the region and removes the content outright — no gradient, no residual edges, nothing to reconstruct. For anything where the cost of a leak is real — IDs, signatures, financial details — the solid box is the honest choice, and the on-page notice says so rather than overselling the blur.

Manual regions and optional face detection

You draw regions by dragging on the image; each can be a rectangle or an ellipse, and an ellipse frames a face more tightly than a box. Regions stack, Undo removes the last, and Clear removes them all, all working with touch as well as mouse. Pressing "Detect faces" loads Google's MediaPipe BlazeFace short-range model on demand — it is never fetched unless you ask — and turns each detected face into a normal, editable region. The short-range model is tuned for faces within about two metres, so it can miss small, distant or side-turned faces; treat it as a first pass and check every face by eye. If the model cannot load, the tool tells you and manual mode carries on unaffected.

What the saved file does and doesn't carry

Exporting rebuilds the image on a canvas and re-encodes it, which strips EXIF metadata — including GPS coordinates, camera model and timestamp — so the file you share does not quietly reveal where or when the photo was taken. That is a second, separate privacy win on top of hiding the visible detail. You can keep the original format or save as JPG, PNG or WebP, and the whole process, detection included, runs on your device with nothing uploaded.
