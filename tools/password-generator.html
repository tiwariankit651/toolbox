    🛡️ Security guidance

    • Use a unique password per site — one breach then can't unlock your other accounts.
    • Length beats complexity — a long passphrase is stronger and easier to remember than a short scrambled string.
    • Use a password manager so you only remember one strong master password.
    • Enable two-factor authentication (2FA) wherever it is offered.
    • This tool never stores or transmits anything — generation and checking happen entirely in your browser using crypto.getRandomValues.
