🎯 Random Name Picker & Team Generator

Enter names (one per line), then pick randomly or make teams.

How to Use This Tool

Class mein random student pick karna hai? Giveaway winner decide karna hai? Names daalo, spin karo — fair aur unbiased selection!

  1. Names enter karo — ek line mein ek naam, ya comma se separate karo
  2. Mode choose karo — Pick Random, Pick Multiple, Make Teams, ya Shuffle
  3. Button dabao — animation ke saath result aayega
  4. Dubara pick karna hai? Reset karo aur phir se spin karo. History bhi save hoti hai!

Common Use Cases

  • Randomly selecting winners for giveaways or contests
  • Choosing students for classroom participation fairly
  • Picking team members for group assignments
  • Deciding who goes first in games or presentations
  • Making unbiased selections for raffle draws

About This Tool

Pick random names and generate balanced teams with cryptographically fair randomization. Enter names (one per line), then use four modes: Pick Random (select one name), Pick Multiple (select 2+ names), Make Teams (divide into 2-10 balanced groups), and Shuffle (randomize entire list). Uses crypto.getRandomValues() for truly unbiased results. Keeps a history of picks. Perfect for teachers selecting students, event organizers making teams, game nights, giveaway winners, and group project assignments.
