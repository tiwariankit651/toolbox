About This Tool

A full-featured scientific calculator that works in your browser. Perform basic arithmetic, trigonometric functions (sin, cos, tan), logarithms (log, ln), square roots, powers, factorials, and more. Supports keyboard input. Perfect for students, engineers, and daily calculations.

How to Use

  1. Click buttons or type on keyboard
  2. Use sin, cos, tan for trigonometry (in degrees)
  3. Use log, ln for logarithms
  4. Use ^ for powers, ! for factorial
  5. Press = or Enter to calculate

Supported Functions

This scientific calculator supports basic arithmetic, trigonometric functions (sin, cos, tan), logarithms (log base 10, natural log), square root, powers, factorial, pi, and Euler's number. Calculation history is shown below. Works offline after first visit.
