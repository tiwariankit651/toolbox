About This Tool

Plot mathematical functions and equations on an interactive graph. Supports linear (y=mx+c), quadratic (x*x), polynomial, trigonometric (Math.sin, Math.cos, Math.tan), logarithmic (Math.log), square root (Math.sqrt), absolute value (Math.abs), and custom JavaScript expressions. Plot two equations simultaneously in different colors to compare. Adjust X-axis range, download the graph as PNG. Includes preset buttons for common functions. Great for math students visualizing equations, teachers creating teaching materials, and anyone learning algebra and calculus.
