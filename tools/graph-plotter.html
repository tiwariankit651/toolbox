How to Use This Tool

Math equation ka graph dekhna hai? y = x², sin(x), kuch bhi — type karo, plot ho jayega. Homework aur assignments ke liye perfect.

  1. Equation enter karo — x^2, sin(x), 2*x+3, jo bhi function hai
  2. X-axis aur Y-axis ka range set karo — zoom in/out ke liye
  3. Plot button dabao — graph coordinate plane pe dikh jayega
  4. Multiple functions add karo compare karne ke liye — ek hi graph pe sab dikhega. Screenshot lo assignment ke liye!

Common Use Cases

  • Visualizing mathematical functions for homework and study
  • Comparing multiple equations on the same coordinate plane
  • Understanding function behavior like intercepts and asymptotes
  • Creating graphs for math presentations and reports
  • Exploring trigonometric, polynomial, and exponential functions

About This Tool

Plot mathematical functions and equations on an interactive graph. Supports linear (y=mx+c), quadratic (x*x), polynomial, trigonometric (Math.sin, Math.cos, Math.tan), logarithmic (Math.log), square root (Math.sqrt), absolute value (Math.abs), and custom JavaScript expressions. Plot two equations simultaneously in different colors to compare. Adjust X-axis range, download the graph as PNG. Includes preset buttons for common functions. Great for math students visualizing equations, teachers creating teaching materials, and anyone learning algebra and calculus.
