Is my data safe?

Absolutely. All processing happens in your browser using JavaScript. Your files and data are never uploaded to any server. We physically cannot access your data.

How does it handle nested JSON objects?

Nested objects are flattened using dot notation. For example, {"user": {"name": "John"}} becomes a column header "user.name" with value "John".

What JSON format is supported?

The JSON to CSV mode expects a JSON array of objects, e.g. [{"name":"Alice","age":30},{"name":"Bob","age":25}]. Each object becomes a CSV row.

About This Tool

Convert between JSON and CSV formats instantly in your browser. The JSON to CSV mode takes a JSON array of objects and produces a CSV file with headers derived from object keys. Nested objects are automatically flattened using dot notation (e.g., "address.city"). The CSV to JSON mode parses CSV text with headers and produces a clean JSON array of objects. Features include bidirectional conversion, nested object flattening, one-click copy, and file download. Perfect for data analysts, developers working with APIs, and anyone who needs to transform data between these common formats.
