FAQ

How do I specify pages?

Use comma-separated numbers (1,3,5) or ranges (1-3) or both (1-3,5,8-10).

Frequently Asked Questions

What ways can I split a PDF?

Five modes: Extract selected pages (tick thumbnails), Custom range like 1-3,5,8-10, Split every N pages, Split into individual one-page PDFs, and Split in half. Quick-preset buttons also cover every page separately, odd pages, even pages, extract first page, and custom range. A live forecast tells you how many output files and pages each will contain before you run it.

Can I rotate or drop pages before splitting?

Yes. Each page thumbnail has a rotate button (90° per click) and a delete/restore toggle. Deleted pages are excluded from all output, and any rotation you apply is baked into the result. A running summary shows how many pages are selected, deleted and rotated so you can confirm the outcome before extracting.

How do the selection shortcuts work?

In "Extract selected pages" mode you get Select All, Deselect All, Select Odd, Select Even and Invert buttons, plus keyboard shortcuts: Ctrl+A for all, N for none, O for odd, E for even and I for invert. There's also a "Copy page range" button that turns your current selection into a compact range string like 1-3,7 to paste into other tools.

How do I get the output when it makes multiple files?

A single result (selected pages, a range, or one half) downloads as one PDF. When a mode produces several files — individual pages, every-N chunks, or both halves — they're bundled into a ZIP automatically. Everything runs in your browser via pdf-lib and JSZip; nothing is uploaded, and your last-used split mode is remembered locally under pdfSplitterMode.

Reading the output forecast before you split

The single most useful habit with this splitter is to read the live forecast line before clicking Split/Extract. As you tick thumbnails or change the mode, the tool recalculates exactly what it will produce — for example "→ 1 PDF with 7 pages", "→ 4 PDFs (3 pages each, last has 1)", or "→ 12 PDFs, one page each (ZIP)". If the forecast says "No pages selected" or "No valid pages in range", the split will refuse to run, so the forecast is your check that the operation is set up correctly.

Why single files download directly and others arrive as a ZIP

The tool decides the delivery format by counting outputs, not by the mode name. Selected pages, a custom range, or one half each resolve to a single PDF and download straight away. Modes that generate several files — individual pages, every-N chunks, or both halves of a split — are bundled with JSZip into one archive (split_pages.zip). This matters when you expect one file and get a ZIP: it means your range or selection resolved to more than one output. Everything runs locally through pdf-lib and pdf.js, so nothing is uploaded.

How rotation and deletion actually affect the result

Deleting a page is not cosmetic. A deleted page is removed from every mode's output and is automatically deselected, so even "Select All" and range parsing skip it. Rotation is baked in: each 90° click adds to the page's existing rotation, and at export the tool reads the page's current angle and adds your rotation on top, so a page that was already landscape stays correct. The running summary ("5 of 10 pages selected · 2 deleted · 1 rotated") is the quickest way to confirm the document state before extracting.

Getting page ranges right

Range syntax accepts comma-separated numbers and hyphenated ranges together, such as 1-3,5,8-10. Pages are 1-based in what you type but the parser clamps to the document: numbers below 1 or above the last page are silently dropped rather than causing an error, and any page you deleted is filtered out of the range too. A few things to keep in mind:

  • A reversed range like 10-8 produces nothing, because the loop runs from the lower to the higher bound only.
  • "Split every N pages" chunks the surviving (non-deleted) pages in document order, so the last file may contain fewer than N pages.
  • The Copy page range button turns your current tick selection back into a compact string like 1-3,7, which is handy for reusing the same selection elsewhere.

Confirming the extraction worked

After splitting, the result line reports the output size (or the number of PDFs and ZIP size for multi-file runs). Open the downloaded PDF and check the page count against the forecast — they should match. If a file fails to load, the tool shows the pdf-lib error message rather than failing silently; the usual fix suggested is to re-save the source PDF and upload it again, which resolves many malformed or encrypted-structure files.
