    Frequently Asked Questions

    Does my Word file get uploaded to a server?

    No. The .docx is opened, edited and turned into a PDF in this tab, so the document is never sent anywhere. The page only loads its libraries and free fonts from public CDNs. After the PDF is made there is an optional 'Upload the PDF to a link' box: it sends the PDF only to an address you type in yourself, and only when you press Upload.

    Can I sign the document or change text before making the PDF?

    Yes. Press 'Edit, sign or add images first'. The pages open in an editor where you can click any paragraph or table cell and retype it, draw or type a signature, add a signature from a photo (its white background is removed), add any image, or add a text box such as a date. Items can be dragged, resized with the round handle and removed with ✕. Then press 'Create PDF with my changes'. The original .docx file is not changed.

    Why can the PDF have a different number of pages than Word?

    Word decides where each page ends using its own text engine and the fonts installed on your computer. This tool lays the text out again in the browser. Calibri, Cambria, Arial, Times New Roman and Courier New are swapped for free fonts with the same letter widths (Carlito, Caladea, Arimo, Tinos, Cousine), so lines usually break in the same places, but a page can still end a few lines earlier or later. The file box shows Word's own page count so you can compare.

    Can I search or copy text in the converted PDF?

    Yes, when 'Make text selectable & searchable' is ticked. Each page is stored as a picture, and an invisible text layer is placed over it line by line, so Ctrl+F and copy work. That layer uses a standard PDF font, so it covers English and other Latin-script text; Hindi and other Devanagari text is visible in the PDF but is not searchable.

    Which Word features are not converted?

    Charts, SmartArt and old EMF/WMF images are not drawn, and text boxes are placed only approximately. Comments are left out and tracked changes are shown as accepted. The table of contents keeps the page numbers Word last saved. The tool tells you in the notes under the Convert button when your file contains any of these. Old .doc files (Word 97–2003) must be saved as .docx first.

    How to Use This Tool

    1. Step 1: Drop your .docx file in the box or click it to pick one. The page count and page size from the document show up straight away.
    2. Step 2: Pick a quality. Standard keeps the file small for email and portal uploads; High sharpens very small text; Print is for paper copies and makes the largest file.
    3. Step 3: Leave the page size on "As set in the document" unless a portal insists on A4 or Letter.
    4. Step 4: Press Convert — or, to change a word, sign or add a picture first, press "Edit, sign or add images first", make the changes on the page and press "Create PDF with my changes".
    5. Step 5: Check the previews and any notes, then download, open or share the PDF — or upload it to a link of your own.

    About This Tool

    This converter reads the Word file in your browser, lays each section out at the page size and margins stored in the document, splits the content into pages, repeats the header and footer on every page with the correct page number, and writes the pages into a PDF. A text layer can be added on top of every page image so you can still search the PDF and copy text out of it. Because the conversion runs on your own device there is no file-size limit set by a server and nothing is stored anywhere — closing the tab clears it. It works with the modern .docx format used by Word 2007 and later, Google Docs (File → Download → .docx), LibreOffice and WPS Office.

    Getting a PDF that looks like your Word file

    A Word document does not store pages. It stores paragraphs, tables and pictures plus a page size and margins, and Word works out where each page ends every time the file is opened. That is why the same .docx can run to a different page count on two computers with different fonts. Any converter, including this one, has to repeat that layout work, so knowing what drives it helps you get a faithful PDF.

    Fonts decide the page breaks

    Line length depends on the width of every letter. If the font Word used is missing, the browser substitutes another one, lines wrap differently and the page breaks drift. This tool maps the five most common Office fonts to free fonts built with identical letter widths: Calibri to Carlito, Cambria to Caladea, Arial to Arimo, Times New Roman to Tinos and Courier New to Cousine. Documents in those fonts usually break in the same places as in Word. A document set in a decorative or paid font falls back to a standard sans-serif font, which keeps the text readable but can move breaks by a few lines. If an exact match matters, change the font to one of the five above before converting.

    Page size, margins and sections

    Each Word section keeps its own page size, orientation and margins, and the converter respects them. A report with a landscape table in the middle produces landscape pages for just that part, and A4 or Letter is taken from the file. The "Page size" option forces A4 or Letter on every page — use it only when a portal asks for one, because the text is then reflowed to the new width. Hard page breaks (Ctrl+Enter) and "page break before" paragraph settings always start a new page.

    Long tables, headers and page numbers

    A paragraph that does not fit at the bottom of a page is split between lines, and a table is split between rows, never through the middle of a row. If the first rows of a table are marked "Repeat as header row at the top of each page" in Word, they are repeated on every page the table spans. Headers and footers are repeated on each page, and PAGE and NUMPAGES fields — "Page 3 of 9" — are filled in with the real numbers. The first-page header is used when the section is set to a different first page.

    Choosing a quality setting

    Every page is drawn as an image at the quality you choose. Standard, the default, is about 144 DPI: text reads cleanly on screen and the file stays small enough for email and most upload portals. High is about 192 DPI and helps with very small print such as footnotes. Print is about 288 DPI for paper copies and makes the file roughly twice the size of High. Because every page is an image, a long document grows with its page count: a plain-text page is roughly 250 KB at Standard. If a portal sets a strict size limit, convert at Standard, or run the result through the PDF Compressor. The text layer is unaffected by this setting, so search and copy work at every quality.

    Editing and signing before you convert

    "Edit, sign or add images first" opens the laid-out pages in an editor instead of converting straight away. Text changes are made on the page itself: click a paragraph or a table cell and type. Each page keeps its size, so added text pushes the rest of that page down but does not flow onto the next page; if a page gets more text than fits, it is outlined in red and a warning appears, because those lines would be cut off. A drawn or typed signature is cropped to the ink, so it can be placed tightly on a signature line; a photographed signature works best on plain white paper, and its background is made transparent. Everything you add is drawn into the page image at the size you set, so it prints exactly where it appears in the editor. The Word file itself is not modified — to keep the changes in Word as well, make them in Word.
