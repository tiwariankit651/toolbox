## ⚠️ POTENTIAL DUPLICATES / OVERLAPS

### Same functionality, different tools:
1. **text-compare** vs **plagiarism-checker** vs **diff-checker** — All compare texts
2. **todo** vs **kanban** — Both are task management boards
3. **handwriting** vs **handwriting-practice** — Both related to handwriting
4. **stopwatch** vs **countdown** vs **presentation-timer** — Timer variants
5. **text-humanizer** vs **paraphraser** — Both rewrite text

### Tools that could be merged:
- text-compare + plagiarism-checker → Keep both (different algorithms, different use cases)
- todo + kanban → Keep both (todo is simple, kanban is advanced project management)
- handwriting + handwriting-practice → Keep both (one creates assignments, other is for learning)
