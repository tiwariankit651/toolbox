🔢 Binary, Hex, and Decimal Conversion Explained for Beginners

May 2026 · 5 min read

If you are learning programming, computer science, or electronics, you will encounter different number systems constantly. Computers think in binary, programmers often use hexadecimal, and humans prefer decimal. Understanding how to convert between these systems is fundamental to working with computers at any level. This guide breaks down each system and shows you how conversions work.

The Three Number Systems

Decimal (Base 10)

This is the number system you use every day. It has ten digits: 0 through 9. Each position represents a power of 10. The number 253 means: 2×100 + 5×10 + 3×1.

Binary (Base 2)

Computers use binary because electronic circuits have two states: on (1) and off (0). Binary has only two digits: 0 and 1. Each position represents a power of 2. The binary number 1101 means: 1×8 + 1×4 + 0×2 + 1×1 = 13 in decimal.

Hexadecimal (Base 16)

Hexadecimal (hex) uses sixteen symbols: 0-9 and A-F (where A=10, B=11, C=12, D=13, E=14, F=15). It is popular in programming because one hex digit represents exactly four binary digits, making it a compact way to write binary values. The hex number 1F means: 1×16 + 15×1 = 31 in decimal.

Why Do Programmers Use Different Bases?

  • Binary — represents how data is actually stored in memory and processed by CPUs
  • Hexadecimal — compact representation of binary; used for memory addresses, color codes (#FF5733), MAC addresses, and byte values
  • Decimal — human-readable; used for user-facing values, calculations, and everyday math

Conversion Examples

Decimal to Binary

To convert decimal 42 to binary, repeatedly divide by 2 and record remainders:

  • 42 ÷ 2 = 21 remainder 0
  • 21 ÷ 2 = 10 remainder 1
  • 10 ÷ 2 = 5 remainder 0
  • 5 ÷ 2 = 2 remainder 1
  • 2 ÷ 2 = 1 remainder 0
  • 1 ÷ 2 = 0 remainder 1

Read remainders bottom-to-top: 42 decimal = 101010 binary

Binary to Hexadecimal

Group binary digits into sets of four (from right to left), then convert each group:

1010 1010 → A A → hex AA
1111 0011 → F 3 → hex F3

Hexadecimal to Decimal

Multiply each hex digit by its positional power of 16:

hex 2F = 2×16 + 15×1 = 32 + 15 = 47 decimal

Real-World Use Cases in Programming

CSS Color Codes

Web colors use hex notation. The color #FF8800 breaks down as: Red=FF (255), Green=88 (136), Blue=00 (0). Understanding hex helps you tweak colors without a color picker.

Debugging Memory

Debuggers display memory addresses and byte values in hex. A memory address like 0x7FFF5FBFF8A0 is much easier to read than its binary equivalent (which would be 47 digits long).

Bitwise Operations

When working with flags, permissions, or network protocols, you manipulate individual bits. Understanding binary lets you use AND, OR, XOR, and shift operations confidently.

File Formats and Protocols

File headers, network packets, and encryption keys are typically represented in hex. Reading a hex dump of a file helps you understand its internal structure.
