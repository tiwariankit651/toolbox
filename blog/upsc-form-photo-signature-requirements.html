📋 UPSC Form Photo & Signature Requirements 2026

June 2026 · 12 min read

UPSC Civil Services exam — IAS, IPS, IFS — India ki sabse prestigious exam hai। Lakho students saalon ki preparation ke baad form fill karte hain। Aur phir ek chhoti si galti — photo ya signature galat format mein upload — aur application reject। Har saal hazaron forms sirf technical photo/signature issues ki wajah se reject hote hain। Yeh guide aapko exactly batayegi ki UPSC 2026 mein photo aur signature ki kya specifications hain, common rejection reasons kya hain, aur free tools se kaise perfectly prepare karein — bina studio jaaye, bina paisa kharch kiye।

UPSC Photo Specifications 2026 — Exact Requirements

UPSC har saal apne notification mein clearly photo specifications mention karta hai। Yeh 2026 ke official requirements hain:

Dimensions and Size

  • Physical Size: 2 x 2.5 inches (width x height)
  • Pixel Dimensions: 600 x 750 pixels (at 300 DPI) — recommended minimum 200 x 230 pixels
  • File Size: Minimum 20 KB, Maximum 300 KB
  • Format: JPEG/JPG only (PNG accepted nahi hoti)
  • Aspect Ratio: 4:5 (width:height)

Photo Quality Requirements

  • Background: Plain white ya light grey — koi pattern, shadow, ya color nahi hona chahiye
  • Recency: Photo last 6 months ke andar li honi chahiye — purani photo mat lagao
  • Face Coverage: Face photo area ka 50-70% cover karna chahiye
  • Both Ears Visible: Dono kaan clearly dikhne chahiye — hair se covered nahi hone chahiye
  • No Sunglasses: Spectacles allowed hain (non-reflective), but sunglasses strictly nahi
  • Expression: Neutral expression, mouth closed, direct camera mein dekh rahe ho
  • Name and Date: Photo ke neeche candidate ka naam aur photo lene ki date printed honi chahiye

Important: Name aur date wali requirement bahut logo miss karte hain। Photo ke neeche white strip mein apna naam aur date clearly likhi honi chahiye। Yeh aap Date on Photo tool se easily add kar sakte ho।

UPSC Signature Specifications 2026

  • Physical Size: 2 x 0.8 inches (width x height)
  • Pixel Dimensions: 600 x 240 pixels (at 300 DPI)
  • File Size: Minimum 10 KB, Maximum 200 KB
  • Format: JPEG/JPG only
  • Ink Colour: Black ink on white paper — blue ink bhi acceptable hai but black preferred
  • Style: Running hand signature — block letters mein naam likhna signature nahi maana jayega
  • Consistency: Signature wahi honi chahiye jo aapke ID proof (Aadhaar, PAN) mein hai
  • Background: Pure white — yellowish paper, ruled paper, ya lined paper accept nahi hoga

Common Rejection Reasons and Fixes

UPSC form reject hona devastating hai — ek saal ka wait aur। Yeh sabse common reasons hain rejection ke, aur kaise fix karein:

1. File Size Exceed (Most Common)

Problem: Photo 300 KB se zyada hai ya 20 KB se kam hai।

Fix: Image Compressor open karo, photo upload karo, target size set karo (ideal 100-250 KB ke beech), aur download karo। Quality maintain hogi aur size limit mein aa jayega।

2. Wrong Dimensions

Problem: Photo 2x2 inches hai (passport size) jabki UPSC ko 2x2.5 inches chahiye। Ya fir random crop kiya hai toh aspect ratio galat hai।

Fix: Image Resizer mein exactly 600x750 pixels set karo। Tool automatic crop guide bhi deta hai taaki face center mein rahe।

3. Wrong Format (PNG instead of JPG)

Problem: Phone se photo li toh PNG mein save hui, ya screenshot li hai PNG mein। UPSC sirf JPG accept karta hai।

Fix: Image Resizer ya Compressor tool automatically JPG output deta hai। Ya explicitly format convert karo — PNG to JPG conversion free hai hamare tools mein।

4. Background Not White

Problem: Photo ghar mein li hai — peeche curtain dikh raha hai, ya wall ka color cream/yellow hai।

Fix: Background Changer tool use karo — existing background remove hoga aur white background automatically add ho jayega। Studio jaane ki zaroorat nahi।

5. Photo Too Old

Problem: 2-3 saal purani photo use ki hai — appearance significantly change ho gayi hai (beard, hair length, weight)।

Fix: Naya photo lo। Ghar mein white wall ke saamne phone camera se le sakte ho — proper lighting mein।

6. Signature on Ruled/Colored Paper

Problem: Notebook ke page pe sign kiya — blue lines dikh rahi hain background mein।

Fix: Clean white A4 paper pe sign karo। Ya Signature Maker tool se digital signature banao — guaranteed white background milega।

7. Name/Date Missing on Photo

Problem: UPSC requires naam aur date photo ke neeche printed honi chahiye — most people miss karte hain।

Fix: Date on Photo tool use karo — photo upload karo, naam type karo, date select karo, aur tool automatically neeche white strip mein print kar dega।

Step-by-Step: UPSC Signature Prepare Kaise Karein

Method 1: Paper Signature Scan

  1. Clean white A4 paper lo — koi lines, marks nahi hone chahiye
  2. Black ink pen se sign karo — medium thickness, confident strokes
  3. Phone camera se photo lo — shadow avoid karo, proper light mein lo
  4. Signature ke around tightly crop karo
  5. Image Resizer mein 600 x 240 pixels set karo
  6. File size 10-200 KB mein ensure karo — compress if needed

Method 2: Digital Signature (Signature Maker Tool)

  1. Signature Maker tool open karo
  2. Mouse ya touchscreen se sign karo — jaise paper pe karte ho waisa hi karo
  3. Black color select karo, white background automatic hai
  4. Multiple attempts lo — best wala select karo
  5. Download karo — already correct format mein milega
  6. Resize karo agar dimensions exact 600x240 chahiye

What To Do If Your Application Gets Rejected

Agar UPSC ne aapka form reject kar diya photo/signature issues ki wajah se, toh panic mat karo. Follow these steps:

Step 1: Check the Rejection Reason

UPSC usually email ya dashboard pe rejection reason batata hai — "photo not as per specification," "signature unclear," etc. Exact reason note karo.

Step 2: Correction Window

UPSC ek correction window deta hai application submit karne ke baad (usually 1-2 weeks). Is window mein aap photo aur signature re-upload kar sakte ho. Agar correction window mein fix kar liya, toh form accept ho jayega.

Step 3: Fix the Specific Issue

Rejection reason ke according fix karo — dimensions galat thi toh resize karo, size exceed thi toh compress karo, background issue tha toh change karo. Is baar double-check karo sab specifications.

Step 4: If Correction Window is Closed

Unfortunately, agar correction window bhi nikal gayi aur form reject ho gaya, toh us attempt ke liye kuch nahi ho sakta. Next year ke liye sab advance mein prepare karke rakho. Isliye deadline ke last day pe form mat bharo — pehle hi fill karo taaki correction ka time mile.

Pro Tips for UPSC Aspirants

  • Photo aur signature advance mein taiyaar karo: Form notification aate hi same day photo aur signature prepare karo. Last minute pe studio mein rush hota hai, online tools mein koi rush nahi।
  • Multiple copies save karo: Different sizes mein 2-3 copies save karo — original high-res, UPSC sized, aur extra compressed version. Kab kahan zaroorat pad jaye।
  • Phone mein bhi rakho: Photo aur signature ki ready files phone mein bhi save karo — agar laptop pe koi issue aaye toh phone se upload kar sako।
  • Friend se verify karao: Submit se pehle kisi friend ko dikha do — fresh eyes se dekhne pe issues jaldi dikhte hain jo humein nahi dikhte।
  • Test upload karo: UPSC form mein photo upload karne ka option deta hai preview ke saath — upload karo, preview check karo, clear dikh raha hai toh proceed karo।

Frequently Asked Questions

Q1: Kya main selfie photo UPSC form mein laga sakta hoon?

Technically upload toh kar sakte ho, but selfie recommend nahi ki jaati. Front camera mein face distortion hota hai (nose bada dikhta hai, proportions galat lagti hain). Aur most selfies mein background clean nahi hota. Best practice: back camera se kisi ko photo lene bolo, white wall ke saamne, natural light mein. Quality bahut better hogi aur acceptance chances bhi zyada.

Q2: Meri photo 500 KB ki hai — kaise 300 KB mein laoon bina quality kharab kiye?

Image Compressor tool use karo. Yeh smart compression use karta hai jo file size reduce karta hai but visual quality almost same rakhta hai. 500 KB se 200-250 KB mein laana easily possible hai bina koi visible quality loss ke. JPEG quality 75-85% pe usually sweet spot hota hai — file size kam, photo clear.

Q3: Photo mein name aur date kaise print karein?

Hamare Date on Photo tool mein photo upload karo, name field mein apna naam type karo (exactly jaise UPSC form mein hai), date select karo, aur tool automatically photo ke neeche ek white strip mein naam aur date print kar dega. Font size aur position automatic adjust hota hai. Download karo aur direct form mein use karo.

Q4: Kya digital signature (mouse/touchscreen se banayi) accept hogi UPSC mein?

Haan, UPSC digital signature accept karta hai as long as it looks like a genuine hand-written signature. Block letters mein naam likhna accept nahi hoga — running hand signature chahiye. Signature Maker tool se mouse ya finger se sign karo, multiple baar try karo, best wala select karo. Important: signature consistent honi chahiye — wahi style jo aap normally use karte ho aur jo aapke ID mein hai.

Q5: UPSC ne mera photo reject kar diya — kya main dubara upload kar sakta hoon?

Haan, agar correction window open hai toh aap photo/signature dubara upload kar sakte ho. UPSC usually form submission ke baad 1-2 weeks ki correction window deta hai. Dashboard pe login karo, rejected photo/signature replace karo nayi correct file se, aur resubmit karo. Isliye form early fill karo — deadline ke last day pe koi correction ka chance nahi milega.

Q6: Studio mein photo kitne ki padti hai aur kya ghar pe free mein ho sakta hai?

Studio mein UPSC specification photo usually 200-500 rupees lagti hai (area ke hisaab se). Ghar pe bilkul free mein ho sakta hai — white wall ke saamne photo lo, Background Changer se white background ensure karo, Date on Photo se naam-date add karo, Image Resizer se exact dimensions set karo, aur Image Compressor se file size perfect karo. Total cost: zero. Total time: 5-10 minutes.
