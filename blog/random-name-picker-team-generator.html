🎯 Random Name Picker and Team Generator

April 2026 · 3 min read

Need to pick a random student, make fair teams, or shuffle a list? Our name picker uses cryptographically secure randomization for truly fair results.

Features

  • Pick Random — select one random name from the list
  • Pick Multiple — select 2, 3, or more names at once
  • Make Teams — automatically divide names into balanced teams
  • Shuffle — randomize the entire list order
  • History — see previous picks

Perfect For

  • Teachers — pick students for questions or presentations
  • Sports — make fair teams for games
  • Events — giveaway winners, raffle draws
  • Group projects — assign random groups

Enter names one per line, then use any of the four modes. Uses crypto.getRandomValues() for truly random, unbiased results.
