💕 How a Love Calculator Works

October 2026 · 7 min read

A love calculator takes two names and returns a percentage. It is a toy, it has no predictive value whatsoever, and the interesting question is a different one: how does it produce a number, and why does the same pair of names always give the same answer?

How the number is produced

Almost every implementation works the same way. The two names are combined, each character is converted to a number, those numbers are folded together with some arithmetic, and the result is reduced to the range 0 to 100.

A simple version: sum the character codes of both names, take the remainder when divided by 101. That gives a number between 0 and 100 that depends only on the letters.

The traditional pen-and-paper method, which some versions imitate, is older: write both names, count how many times each letter of a word like "LOVES" appears across them, then repeatedly add adjacent digits until two digits remain.

Either way the output is deterministic. The same two names always give the same percentage, because nothing random is involved — it is a hash of the input.

Why the same names always match

This is the part people notice and find slightly eerie. You try it, get 73%, try again next week, still 73%.

There is nothing stored and nothing remembered. The calculation is a pure function of the two strings, so it cannot give a different answer unless the input changes. Swap a nickname for a full name and the number changes completely, which is the clearest demonstration that it is arithmetic on letters rather than anything about people.

Try it: the same person's name with and without a middle name gives two unrelated percentages. Both cannot be meaningful.

Why a random number would be worse

Interestingly, determinism is the better design for a toy like this.

If the result were random, trying twice would give two answers and the illusion would collapse immediately. Being deterministic makes it feel like a measurement, which is what makes it fun. It is the same reason a fortune cookie works better than a dice roll.

The reason it feels meaningful

Two well-documented effects do the work.

The Barnum effect. People accept vague, generally positive statements as specifically true of them. A number like 78% invites you to supply the reasons it is right, and you will find some.

Confirmation bias. A high score gets remembered and recounted; a low one gets dismissed as "it's just a game". So in memory the calculator has a good hit rate, because the misses were filtered out at the time.

Both are ordinary features of how people reason, not failures of intelligence. Knowing about them does not stop them working, which is itself interesting.

What this is actually similar to

The calculation is a hash function — input of any length, fixed-size output, same input always giving the same output. Hashes are used throughout computing for checking that a file has not changed, for storing passwords, and for distributing data across servers.

A love calculator is a hash function with a playful presentation. That is a reasonable thing to understand from it: the same idea, used seriously, is how your password is checked without the website storing it.

The difference is that a cryptographic hash is designed so similar inputs give completely different outputs, and so the input cannot be recovered from the output. A love calculator's arithmetic has neither property, which is why swapping two letters can give a similar answer.

Privacy, which is not nothing

You are typing two names — often your own and someone else's.

Many of these sites run server-side, which means both names are sent to and logged by somebody's server, usually alongside an advertising identifier. For a toy that is a disproportionate amount of data collection, and several of these sites exist primarily to collect it.

A browser-based version does the arithmetic on your own device. Nothing is transmitted, which for a tool whose entire input is two people's names is the correct default.

Taking it in the right spirit

It is a game, and games are fine. The only thing worth saying is the obvious one: a percentage derived from the letters in two names carries no information about two people. If a low number would genuinely bother you, the honest answer is that the arithmetic does not know either of you.
